N is configured the divisor comes from the document, not from how many peers a node can currently see, so a partition cannot let both halves award themselves the whole cap

The application keeps its pool because the pool it keeps is local. The cap that could not be divided 300 ways is divided six ways, by nodes that agree about the divisor.

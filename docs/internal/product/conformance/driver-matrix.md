## Why this exists beside scripts/conformance.sh

That suite runs the same five drivers against `pgprox-proto`'s
conformance server, which answers whether our codec and our harness
agree with each other. They are the same code, so a misunderstanding
shared between them cannot show up there.

It did not show up there. asyncpg could not run a single parameterised
query through the proxy from M6 until M8, because `Flush` has no
terminator and the relay read until `ReadyForQuery`. The harness
answered a `Flush` the same wrong way, so the suite was green
throughout. This matrix is the check that would have caught it.

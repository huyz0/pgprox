a default build and a FIPS build. The suite is what the proxy logged
for that handshake, not what the driver reported, because only some
drivers will say and the server knows for all of them.

## What this does and does not say

It says which drivers complete a handshake with each build and on what
terms. It does not say anything about a driver pinned to an older TLS
library than the one on this machine, which is the case a FIPS
migration actually breaks. Treat a row here as a floor.

At least one driver negotiated TLS 1.2, which is where FIPS mode
actually restricts the suite list. Those rows are the ones to read.

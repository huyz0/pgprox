## What this does and does not say

It says which drivers complete a handshake with each build and on what
terms. It does not say anything about a driver pinned to an older TLS
library than the one on this machine, which is the case a FIPS
migration actually breaks. Treat a row here as a floor.

Every driver on this machine negotiated TLS 1.3, on both builds. That
is a clean result and a narrow one: TLS 1.3's suites are all
FIPS-approved, so the restrictions FIPS mode imposes were never
reached. `plan.md` expects FIPS to drop ChaCha20-Poly1305 and to
restrict TLS 1.2 to ECDHE with extended master secret, and none of
that was exercised here. The drivers that would meet it are older
builds than the ones this machine has, which is exactly the
population a FIPS migration breaks.
